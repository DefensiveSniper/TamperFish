## 系统结构：软件开发思路
产品等于三个部分。核心理念就是将 LUI（语言交互界面）放在前面，作为整个交互的核心。同时也通过图形界面提供快速查询入口

### 第一个部分：大模型/chatgpt/claude
大模型是脑子，负责思考
### 第二个部分：Agent/openclaw
Agent 负责在数据库和各种工具中来回调用，不停地推理和理解用户的需求，完成固定任务
### 第三个部分：图形界面
只负责交互和数据呈现。如果是要看日程类的，优先选列表式
